# ProposalPilot

Chrome extension (Manifest V3) that reads the freelance job post you are viewing and drafts a tailored proposal with a suggested price and delivery estimate. You always review, edit, and send manually.

**Status:** Phase 0 — project setup

- Backend: see `/backend` after Phase 3

- LLM API keys live only on the backend
